# DNA Sequence Analyzer 🧬

A beginner bioinformatics project that analyzes a disease-associated gene sequence and 
presents the results through an interactive Shiny for Python web app.

## About

This project explores the **HBB gene**, associated with sickle cell anemia and 
beta-thalassemia. Using Biopython, it performs core sequence analysis and displays 
the results in a live, interactive dashboard.

## Features

- 📊 **GC content calculation** — measures the percentage of G/C bases in the sequence
- 🔄 **Reverse complement** — generates the complementary DNA strand
- 🧪 **Transcription** — converts DNA to RNA
- 🧫 **Translation** — converts RNA into its corresponding protein sequence
- 📈 **Nucleotide frequency chart** — visualizes A/T/G/C base counts

- **Python**
- **Biopython** — sequence parsing and analysis
- **Shiny for Python** — interactive web app framework
- **Matplotlib** — data visualization
